公开 · 通用迁移版 v1.0.0

IT 机房运维 · 现场打卡服务

移动端 H5 + Node/SQLite 轻量后端，内置机柜连线拓扑编辑器，附微信小程序源码。任意机器、任意目录可部署。

快速开始

tar xzf it-checkin-migrate.tar.gz
cd it-checkin
sudo bash install.sh

脚本自动完成：目录定位 → npm ci → 可选自签 HTTPS → 可选 systemd 开机自启 → 健康检查。

首次启动会随机生成管理员密码并写入 data/first_password.txt（权限 600），首次登录强制改密，改密后请删除该文件。

下载与文档

下载迁移包（Release） 完整部署文档 README GitHub 仓库

包内包含

  • 后端：server.js、db.js、XLSX/HTML 导出模块
  • Web 前端 public/：打卡、记录、管理、机柜拓扑（含离线依赖）
  • 小程序 miniprogram/：与 Web 共用同一后端
  • 部署：install.sh 一键脚本 + 10 章中文 README

不含真实数据、密钥、证书与固定密码；data/、uploads/ 首次运行自动创建。

迁移旧数据

把旧服务器的 data/ 与 uploads/ 覆盖到新目录后重启，账号、记录、照片、拓扑、水印全部保留。

sudo systemctl stop it-checkin
tar xzf itck-data.tar.gz -C /opt/it-checkin
sudo systemctl start it-checkin
仅供个人与内部运维使用 · 部署后请立即修改管理员密码并妥善备份 data/ 与 uploads/
