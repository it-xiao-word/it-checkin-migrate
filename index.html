快速开始

三步完成部署
bash
# 解压并进入目录
$ tar xzf it-checkin-migrate.tar.gz
$ cd it-checkin
# 一键安装（自动装依赖 / HTTPS / 服务）
$ sudo bash install.sh
  1. 1
    解压将迁移包放到目标目录并解压
  2. 2
    安装npm ci 自动完成，可选 HTTPS
  3. 3
    启动可选 systemd 开机自启 + 健康检查
首次启动随机生成管理员密码并写入 data/first_password.txt（权限 600），首次登录强制改密，改密后请删除该文件。

迁移旧数据

账号 / 记录 / 照片 / 拓扑 / 水印全部保留

把旧服务器的 data/ 与 uploads/ 覆盖到新目录后重启即可，无需其他操作。

停机→覆盖 data / uploads→重启 
sudo systemctl stop it-checkin
tar xzf itck-data.tar.gz -C /opt/it-checkin
sudo systemctl start it-checkin
